# OpenCode 实例只读诊断适配器

本适配器用于补充 ACP 协议未返回的模型目录、默认模型、已注册 Agent 和插件状态。当前仅支持实际验证的 OpenCode **2.0.28**；其他版本保持信息未知，不阻断 ACP。

适配器没有 npm 依赖，不调用模型、不执行工具、不读取认证数据库或密钥，也不修改 OpenCode 配置。没有 SaCode 创建的短期诊断请求时不读取实例上下文。请求绑定随机 nonce、诊断编号、工作目录和实际新建会话；输出仅含有限白名单字段，写入本次检查的临时目录，检查后由 SaCode 清理。

这里使用 OpenCode v2.0.28 的插件对象契约：`setup(ctx)`、`event.subscribe`、`model.list/default`、`agent.list`、`plugin.list`。`Plugin.define` 在该版本是恒等包装，因此无需引入 SDK。契约来源为上游提交 `026b106bc5d41b679ffc413264229c340871e4d3`，不能据此假定其他版本兼容。

## 安装边界

本目录存在不代表已安装到用户的 OpenCode。启用 SaCode ACP 开关也不会安装本适配器。向项目或用户配置添加插件路径需要用户独立授权；有在途委派时不能擅自重启 OpenCode。

测试仅在独占临时配置中声明本适配器和一个本地目录夹具，不更改现有用户配置，不发送模型任务。无适配器时，SaCode 仍可建立 ACP 连接，实例元数据展示为未确认。

## 结果边界

- “已列入目录”仅表示当前实例返回该启用模型，不能证明模型调用成功。
- Agent 的模型未出现在完整启用目录中，单独显示风险，不将整个 ACP 连接判定为不可用。
- 默认模型不等于用户后来显式选择的会话模型。
- 不从名字推断免费；价格、配置文件来源、插件动态路由和实际模型调用保持未知或未验证。
- 不解析任意插件内部数据；已注册 Agent 列表不代表全部动态行为。
