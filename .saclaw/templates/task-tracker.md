# 任务追踪模板

本文档定义了 PCIV 工作流的任务状态追踪格式。

## 状态文件结构

```
docs/pciv-status/
├── current-feature.md      # 当前功能点状态
├── tasks.md                # 任务追踪
├── decisions.md            # 决策记录
├── clarifications.md       # 澄清记录
└── validation-report.md    # 验证报告
```

## 当前功能点状态

**文件**: `current-feature.md`

```markdown
# 当前功能点状态

## 基本信息
| 字段 | 内容 |
|------|------|
| 功能名称 | [功能名称] |
| 开始时间 | [YYYY-MM-DD HH:mm] |
| 当前阶段 | [Prime/Clarify/Implement/Validate] |
| 预计完成 | [YYYY-MM-DD HH:mm] |

## 功能范围
- 粒度: [小/中/大]
- 包含: [功能列表]
- 不包含: [排除项]

## 阶段进度
| 阶段 | 状态 | 开始时间 | 完成时间 |
|------|------|----------|----------|
| Prime | ✅ 完成 | | |
| Clarify | ✅ 完成 | | |
| Implement | 🔄 进行中 | | |
| Validate | ⏳ 待开始 | | |

## 技术栈
| 层级 | 技术 |
|------|------|
| 前端 | [技术] |
| 后端 | [技术] |
| 数据库 | [技术] |

## 最近更新
- [时间] - [更新内容]
- [时间] - [更新内容]
```

## 进度更新命令

### 更新任务状态

```
"任务 T002 已完成"
"任务 T003 开始执行"
"任务 T004 被阻塞，原因：..."
```

### 查看进度

```
/pciv-status
```

### 继续任务

```
/pciv-continue
```

## 相关命令

- `/pciv-status` - 查看状态
- `/pciv-continue` - 继续任务
- `/pciv-mistake` - 记录错题
