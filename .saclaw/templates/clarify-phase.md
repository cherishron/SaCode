# Clarify 阶段模板

## 阶段目标

确认需求细节、消除歧义、完善技术方案、分解任务，获得用户确认后进入实施。

## 工作流程

### 1. 审查 Prime 阶段产出

```bash
# 回顾 Prime 阶段产出
"请回顾 Prime 阶段的产出，确认是否有遗漏或需要调整的地方"
```

**审查清单**：
- [ ] 技术栈识别是否准确
- [ ] 需求理解是否完整
- [ ] 功能范围是否合理
- [ ] 初步计划是否可行

### 2. 识别歧义和未定义项

**歧义类型**：

| 类型 | 示例 | 澄清方式 |
|------|------|----------|
| 功能歧义 | "搜索功能" → 全文搜索？模糊搜索？精确匹配？ | 具体问题 |
| 技术歧义 | "优化性能" → 具体指标？响应时间？并发量？ | 量化指标 |
| 边界歧义 | "用户管理" → 包含权限？角色？审计日志？ | 明确范围 |
| 交互歧义 | "保存数据" → 自动保存？手动保存？草稿？ | 交互流程 |

```bash
# 请求识别歧义
"请识别需求中的歧义和未定义项，生成澄清问题列表"
```

**歧义识别模板**：
```markdown
## 歧义识别

### 已识别的歧义项

| 序号 | 歧义内容 | 类型 | 影响范围 | 优先级 |
|------|----------|------|----------|--------|
| 1 | [歧义描述] | 功能/技术/边界/交互 | [影响描述] | 高/中/低 |
| 2 | [歧义描述] | 功能/技术/边界/交互 | [影响描述] | 高/中/低 |

### 未定义项

| 序号 | 未定义内容 | 建议默认值 | 需要确认 |
|------|------------|------------|----------|
| 1 | [内容描述] | [默认值] | [ ] |
| 2 | [内容描述] | [默认值] | [ ] |
```

**检查清单**：
- [ ] 已识别所有歧义项
- [ ] 已列出所有未定义项
- [ ] 已按优先级排序

**澄清对话示例**：
```
AI: 检测到需求中有以下歧义需要澄清：

Q1: 搜索功能是否需要支持多条件组合？
- A: 是，支持关键词 + 标签 + 分类组合
- B: 否，仅支持单一关键词搜索
建议选择 A，因为根据技术栈（Next.js + Prisma）组合搜索实现成本较低。

用户: 选择 A

AI: 已确认：搜索支持关键词 + 标签 + 分类组合搜索。

Q2: 搜索结果是否需要高亮显示匹配关键词？
- A: 是，需要高亮
- B: 否，暂不需要
建议选择 B，高亮功能可在后续迭代添加。

用户: 选择 B

AI: 已确认：暂不实现高亮功能。
```

**检查清单**：
- [ ] 所有高优先级问题已澄清
- [ ] 澄清结果已记录
- [ ] 用户已确认所有回答

## 常见问题

### Q: 澄清问题太多怎么办？

A: 按优先级排序，先澄清高优先级问题。低优先级问题可以在 Implement 阶段根据实际情况再确认。

### Q: 用户无法立即回答某些问题怎么办？

A: 使用建议默认值暂时推进，标注为"待确认"，在后续阶段再确认。

### Q: 技术方案无法达成一致怎么办？

A: 可以先实现一个最小可行方案（MVP），在 Validate 阶段验证后再决定是否优化。
