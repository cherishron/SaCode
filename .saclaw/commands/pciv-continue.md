# /pciv-continue

继续上一个未完成的任务或恢复工作流。

## 描述

从上次停止的地方继续工作，自动加载上下文和任务状态。

## 用法

```
/pciv-continue
```

## 执行流程

### 1. 加载状态

读取 `docs/pciv-status/` 中的状态文件：
- current-feature.md
- tasks.md
- decisions.md

### 2. 恢复上下文

重新加载：
- 项目上下文
- 技术栈信息
- 当前阶段产出

### 3. 定位任务

确定：
- 当前阶段
- 当前任务
- 下一步操作

### 4. 继续执行

从断点继续工作流。

## 输出

```markdown

### 功能点
- 名称: 文章搜索功能
- 恢复阶段: Implement

### 任务状态
- 当前任务: T002 - 实现搜索 API
- 任务状态: 🔄 进行中
- 已完成步骤: 数据库索引已添加

### 待完成任务
| ID | 任务 | 状态 |
|----|------|------|
| T002 | 实现搜索 API | 🔄 进行中 |
| T003 | 创建前端搜索组件 | ⏳ 待办 |
| T004 | 添加排序切换功能 | ⏳ 待办 |

### 上下文已恢复
- 技术栈: Next.js 14 + Prisma + PostgreSQL
- 搜索方案: PostgreSQL 全文索引
- 验证命令: npx tsc --noEmit

### 继续执行
继续实现搜索 API...
需要我做什么？
```

## 使用场景

### 场景 1：跨会话恢复

```
# 昨天的工作
用户: /pciv-status
AI: 当前有 1 个未完成的功能点

# 恢复工作
用户: /pciv-continue
AI: 已恢复"文章搜索功能"，当前在 Implement 阶段...
```

### 场景 2：中断后恢复

```
# 工作被中断
用户: /pciv-continue
AI: 检测到上次中断在任务 T002，正在恢复...
```

## 相关命令

- `/pciv-status` - 查看状态
- `/pciv-context` - 重新加载上下文
