# /pciv-validate

启动 PCIV 工作流的 Validate（验证）阶段。

## 描述

Validate 阶段是 PCIV 工作流的第四阶段，主要任务包括：
- 类型检查
- 代码风格验证
- 功能测试
- 构建验证
- 生成验证报告

## 用法

```
/pciv-validate [scope]
```

### 参数

| 参数 | 类型 | 描述 |
|------|------|------|
| scope | 可选 | 验证范围：all（默认）、quick（快速） |

## 前置条件

- Implement 阶段已完成
- 所有任务已完成
- 自测已通过

## 执行流程

### 1. 类型检查

```
检查项：
- TypeScript 编译错误
- 类型推断问题
- 类型定义缺失
```

### 2. 代码风格验证

```
检查项：
- ESLint 规则
- Prettier 格式
- 代码规范
```

### 3. 功能测试

```
检查项：
- 单元测试
- 集成测试
- 边界测试
```

### 4. 构建验证

```
检查项：
- 生产构建成功
- 无构建警告
- 资源打包正常
```

### 5. 文档检查

```
检查项：
- API 文档更新
- README 更新
- 注释完整性
```

## 验证失败处理

如果验证发现问题：

```markdown
## Validate 阶段报告

### 验证结果总览

| 验证项 | 状态 | 问题数 |
|--------|------|--------|
| 类型检查 | ❌ 失败 | 3 |
| 代码风格 | ✅ 通过 | 0 |
| 功能测试 | ❌ 失败 | 2 |

### 问题详情

#### 类型错误
1. src/api/search.ts:42 - 参数类型不匹配
2. src/components/SearchBar.tsx:15 - 缺少必需属性
3. ...

### 决策
- 问题类型: 代码实现问题
- 建议返回: Implement 阶段

### 下一步
运行 "返回 Implement" 处理问题
```

## 循环迭代决策

| 问题类型 | 返回阶段 | 命令 |
|----------|----------|------|
| 类型错误 | Implement | "返回 Implement" |
| 代码风格问题 | Implement | "返回 Implement" |
| 测试失败 | Implement | "返回 Implement" |
| 需求偏差 | Clarify | "返回 Clarify" |
| 设计问题 | Prime | "返回 Prime" |
