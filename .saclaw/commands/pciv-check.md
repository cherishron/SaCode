# /pciv-check

快速质量检查命令，支持多种检查类型。

## 描述

执行代码质量检查，包括类型检查、代码风格、测试、安全扫描等。支持即时验证和手动触发两种模式。

## 用法

```
/pciv-check [type]
```

### 参数

| 参数 | 描述 |
|------|------|
| `all` | 完整检查（默认） |
| `type` | 仅 TypeScript 类型检查 |
| `lint` | 仅 ESLint 代码风格检查 |
| `test` | 仅运行测试 |
| `security` | 安全漏洞扫描 |
| `quick` | 快速检查（类型 + lint） |

## 检查类型说明

### type - 类型检查

检测 TypeScript 类型错误：
- 类型推断问题
- 类型定义缺失
- 类型不匹配

```bash
# 执行命令
npx tsc --noEmit
```

### lint - 代码风格检查

检测代码风格问题：
- ESLint 规则违规
- 代码格式问题
- 最佳实践建议

```bash
# 执行命令
npx eslint . --ext .ts,.tsx,.js,.jsx
```

### test - 运行测试

执行测试套件：
- 单元测试
- 集成测试
- 测试覆盖率

```bash
# 执行命令
npm test
```

### security - 安全扫描

检测安全漏洞：
- 依赖漏洞
- 代码安全问题
- 敏感信息泄露

```bash
# 执行命令
npm audit
```

## 即时验证模式

在 Implement 阶段，每次代码变更后自动运行简化检查：

```markdown
### 即时验证
✅ TypeScript 类型检查通过
✅ ESLint 检查通过

变更已验证，可继续开发。
```

## 相关命令

- `/pciv-fix` - 自动修复问题
- `/pciv-validate` - 完整验证阶段
- `/pciv-review` - 代码审查

## 配置

可在项目配置文件中自定义检查规则：

```json
// .iflow/settings.json
{
  "pciv": {
    "check": {
      "type": true,
      "lint": true,
      "test": false,
      "security": false
    }
  }
}
```
