# /pciv-clarify

启动 PCIV 工作流的 Clarify（澄清）阶段。

## 描述

Clarify 阶段是 PCIV 工作流的第二阶段，主要任务包括：
- 审查 Prime 阶段产出
- 识别需求歧义
- 结构化澄清问题
- 确定技术方案
- 分解详细任务

## 用法

```
/pciv-clarify
```

## 前置条件

- Prime 阶段已完成
- 技术栈已识别
- 需求已初步理解

## 执行流程

### 1. 审查 Prime 产出

- 确认技术栈识别准确
- 确认需求理解完整
- 确认功能范围合理

### 2. 识别歧义

自动分析需求中的：
- 功能歧义
- 技术歧义
- 边界歧义
- 交互歧义

### 3. 结构化澄清

生成澄清问题列表，逐一获取用户确认。

### 4. 确定技术方案

基于澄清结果，确定最终技术方案。

### 5. 任务分解

将计划分解为可执行任务，标记依赖关系和可并行项。

### 6. 获得用户确认

展示完整计划，获取用户确认。

## 示例

```
用户: /pciv-clarify

AI: 正在执行 Clarify 阶段...

## 需要澄清的问题

### Q1: 搜索结果是否需要高亮显示关键词？
- A: 是，需要高亮
- B: 否，暂不需要
建议: B（后续迭代添加）
请选择: 

用户: B

AI: 已确认：暂不实现高亮功能。

### Q2: 搜索结果排序方式？
- A: 按相关性排序
- B: 按时间排序
- C: 可切换排序方式
建议: C（灵活性更好）
请选择:

用户: C

AI: 已确认：支持相关性/时间排序切换。

## 技术方案
- 数据库索引: PostgreSQL 全文索引
- API 设计: GET /api/search
- 前端实现: 即时搜索 + debounce

## 任务清单
| ID | 任务 | 预估时间 |
|----|------|----------|
| T001 | 添加数据库全文索引 | 30分钟 |
| T002 | 实现搜索 API | 2小时 |
| T003 | 创建前端搜索组件 | 3小时 |
| T004 | 添加排序切换功能 | 1小时 |

请确认以上方案，输入 "确认" 继续。
```
