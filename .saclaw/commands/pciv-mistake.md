# /pciv-mistake

记录错题到错题本。

## 描述

将开发过程中遇到的错误记录到项目错题本，用于知识沉淀和避免重复犯错。

## 用法

```
/pciv-mistake [type]
```

### 参数

| 参数 | 描述 |
|------|------|
| `type` | 错误类型：type/api/logic/config/performance |
| 无参数 | 交互式记录 |

## 触发时机

错题记录会在以下时机自动触发或建议触发：

1. **Validate 阶段发现错误** - 类型检查失败、测试失败、构建失败
2. **Implement 阶段遇到阻塞** - 同一问题尝试超过 2 次
3. **Clarify 阶段发现理解偏差** - 需求理解与预期不符
4. **用户主动记录** - 使用本命令

## 交互式记录流程

```
用户: /pciv-mistake

AI: 正在启动错题记录...

### 基本信息
1. 请描述错误现象：
   用户: [描述]

2. 请提供错误信息（如有）：
   用户: [错误日志]

### 根因分析
3. 直接原因是什么？
   用户: [原因]

4. 根本原因是什么？
   用户: [原因]

### 解决方案
5. 如何解决的？
   用户: [方案]

6. 如何预防？
   用户: [措施]

### 确认记录
以上信息将记录到错题本，是否确认？(Y/n)
```

## 错误分类

### by-category/
- `type-errors.md` - TypeScript 类型错误
- `api-errors.md` - API 相关错误
- `logic-errors.md` - 业务逻辑错误
- `config-errors.md` - 配置相关错误
- `performance-errors.md` - 性能问题

## 相关命令

- `/pciv-knowledge` - 查看知识库
- `/pciv-review` - 代码审查（基于错题本）
- `/pciv-fix` - 自动修复问题
