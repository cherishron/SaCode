# /pciv-fix

自动修复可修复的代码问题。

## 描述

自动修复 ESLint 可自动修复的问题、格式化代码、修复简单类型问题等。

## 用法

```
/pciv-fix [scope]
```

### 参数

| 参数 | 描述 |
|------|------|
| `all` | 修复所有可修复问题（默认） |
| `lint` | 仅修复 ESLint 问题 |
| `format` | 仅格式化代码 |
| `imports` | 仅修复导入排序 |

## 执行流程

### 1. 扫描问题

首先运行 `/pciv-check` 扫描可修复的问题。

### 2. 分类问题

| 类型 | 可自动修复 | 需人工确认 |
|------|-----------|-----------|
| 代码格式 | ✅ | - |
| ESLint 规则 | ✅ 部分 | 复杂规则 |
| 导入排序 | ✅ | - |
| 类型错误 | ❌ | ✅ |
| 逻辑错误 | ❌ | ✅ |

### 3. 执行修复

自动应用修复并展示变更。

### 4. 验证结果

重新运行检查确认修复成功。

## 注意事项

1. **备份建议**：修复前建议提交或备份代码
2. **审查变更**：修复后请审查变更内容
3. **复杂问题**：复杂问题需要人工处理
4. **测试验证**：修复后建议运行测试
