# SaCode 工作台视觉修订

用户否决第一版原型，选择“更接近 Codex：留白、简洁、对话突出”。本轮由 ui-sketcher 提供布局建议并只读复核，实际实现仍沿用 Electron、Vue runtime + h()、OpenTiny 与客户端槽位。

默认暖白主题，中央对话为主；助手消息使用自然段，不套卡片。左侧项目与会话使用扁平列表，知识库、自动化、扩展和连接放在导航底部。右侧默认仅文件结构、差异审查两个标签。功能入口通过菜单保留，避免把全部能力同时堆在首屏。

宽窗导航 220 CSS px、右栏 380 CSS px，正文最大 720 CSS px；顶部原型标记 32 CSS px。输入区使用紧凑卡片、图标操作、模型与权限选择及唯一主发送按钮。设置使用齿轮，左右侧栏使用不同分区图标，保留可读名称与提示。

1200px 以下收起导航并保留恢复入口；900px 以下切换对话与工作台单视图。主题采用语义色，暗色主题同时设置控件背景和文字；键盘焦点必须可见。

目标操作、标签拆分/聚焦/重排、模型中心与队列操作收进局部菜单；异常场景选择放在“原型检查”弹层。模型中心仍由设置中的同一入口打开。增强直接替换、回退和编辑竞态保护保留。

本轮是独立交互原型修订，所有业务结果显式为模拟。视觉及交互检查不代表核心、Host、CLI 或安装包完成，也不替代用户的视觉认可。实际读数与截图见对应第一批证据文档。
