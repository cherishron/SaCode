# Desktop 原生桌面验收脚本（R1–R2 出口）

> 目标：真机 Tauri 走查，补上「已通过原生桌面验收」这一列。
> 原则：构建成功 ≠ 操作验收。每项按「步骤 → 预期 → 勾选」记录。
> 范围：Local Mode、统一右侧栏、灵枢卡片、多 ACP、布局/草稿恢复。
> 日期：2026-10-12

---

## 0. 环境准备

| 项 | 要求 |
| --- | --- |
| 机器 | 干净或接近干净（可关掉三件套进程） |
| 构建 | `cd interfaces/client-core && npm run build`（dist 同步） |
| Desktop | `cargo build --release -p sacode-desktop` 或开发模式 `npm run tauri dev` |
| daemon | sidecar 自带，或 `SACODE_BINARY_PATH` 指向 `target/debug/sacode.exe` |
| 云 env | **全部不设**（`SACODE_IDP_*` / `GATEWAY_*` / `ENTITLEMENT_*` / `SACODE_OPENCODE_*` / `SACODE_CODEBUDDY_*`） |
| 记录 | 每项截图或一句话；失败项写复现步骤 |
