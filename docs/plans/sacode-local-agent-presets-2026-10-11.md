# SaCode 本地 Agent 预设与自定义模式方案

- 日期：2026-10-11
- 状态：设计提案，未实现、未验收。
- 用户裁决：Agent 不进入市场，改为本地自建；以用户提供的 基线 Agent 预设交互与工具/工作方式为参照。
- 本轮授权：保存方案，不修改业务代码、不提交或发布。
- 关联：[扩展市场方案](sacode-extension-market-2026-10-11.md)。

## 1. 定位与边界

预设是同一 SaCode Agent 运行时的配置，不是另一套 Agent 引擎，也不是运行中的会话、子进程或团队成员。预设选择可见工具、工作指令和工具调用方式，支持内置模式、用户手写及 AI 辅助生成。

创建、管理和使用预设不依赖市场、云账号或发布审核。“本地自建”指配置保存在本机，不表示模型推理一定本地运行；远程模型仍需用户的供应商凭据并遵守服务要求。

外部 ACP Agent 保持独立连接/委派功能。一个预设可在获准时使用委派工具，但导入预设不能隐式安装、启动或登录外部 Agent。

## 2. 内置模式

| 模式 | 意图 | 真正可用的门槛 |
| --- | --- | --- |
| 标准模式 standard | 日常代码、文件与资料任务，按需检索、编辑和运行终端 | 可见工具与实际执行一致，遵守观察、审批和预算规则 |
| PTC 模式 ptc | 批量工具编排及结果筛选、整理、去重与统计 | 有实际受控编排运行时和工具桥接，不能只改提示词或把任意代码裸跑 |
| 极简模式 minimal | 只通过终端工具执行，供测试与对比 | 模型工具目录确实受限，不暗藏文件/MCP 等其他通道；终端不绕过权限 |
| 创造模式 creator | 对话编写 SaCode 插件、Skill 与自定义预设 | 对接真实创建、校验、预览及授权安装流程；不能因使用此模式自动开放任意执行 |

创造模式参考 基线 的 cordis 意图，但不宣称 SaCode 已兼容 Cordis 插件源码。内置模式标识是本方案建议，具体配置需按上游和现有运行时契约核实。尚无执行能力的模式显示未就绪及原因，不能以静态卡片冒充可用。

内置预设不可直接覆写，可复制后自定义。标准模式作为首次新任务默认；用户可指定其他已就绪预设为新任务默认。

## 3. 预设定义

建议使用版本化、可校验的声明式定义与独立指令正文。最终文件格式实施前结合现有配置加载机制冻结，不在方案阶段宣称已有兼容 Schema。

| 字段组 | 内容 |
| --- | --- |
| 身份 | schemaVersion、稳定 id、名称、说明、定义修订 |
| 来源与范围 | 内置/用户自建/项目自建、用户级或项目级 |
| 工作指令 | 职责、执行方式和指令正文；不是可覆盖系统规则的最高级提示 |
| 工具集合 | 显式工具身份或经解析的组；MCP 引用服务器与工具身份 |
| Skill 引用 | 稳定身份及作用域；运行时记录实际解析版本 |
| 执行方式 | 标准工具调用或已支持的 PTC；未知方式拒绝加载 |
| 模型 | 沿用当前选择或引用模型配置，不包含密钥 |
| 预算 | 轮次、token、工具调用及时间限制；不允许扩大用户授权上限 |
| 权限申请 | 希望使用的能力，不是自动批准记录 |

有效权限取系统策略、用户授权、会话策略与预设工具集合的交集；指令和权限申请不能放宽该交集。缺依赖、工具未知、模型不可用或 Schema 非法时返回明确诊断，不自行更换用户选择的模型池条目或降级工作方式。同一条目内的上游故障切换、暂停与恢复探测沿用既定模型中心规则并记录实际路由，不要求用户重复确认已有授权；不能加入未经授权的供应商或重放结果未知的副作用。

## 4. 本地存储与作用域

预设定义、默认选择与运行记录分开存储。建议项目定义在受控的项目配置目录、用户定义在 SaCode 用户配置目录，具体路径实施前核对现有约定。

用户级与项目级同名预设在 UI 中保留来源区分，引用使用作用域与稳定 id，不能按展示名误选。项目提供的定义首次使用需信任确认，不能因打开仓库就自动生效。项目默认选择只对可信项目生效，不覆写全局默认。

保存使用 expectedRevision 检查与原子写入，避免桌面、CLI 或 AI 同时编辑互相覆盖。删除前显示运行与引用影响，不删除关联 Skill/MCP。运行中的任务使用启动时冻结的预设修订，后续修改只影响新任务。

## 5. 创建、编辑与使用

1. 用户从内置预设复制，手动编辑，或点击“让 Agent 帮我创建预设模式”。
2. AI 生成候选定义，说明工具、依赖与权限；生成结果是未信任草稿，不自动保存启用。
3. 校验定义、依赖、模型、平台支持与工具集合，展示与原修订差异。
4. 用户确认保存范围和内容；默认预设变更单独显式选择。
5. 创建新任务时解析预设，冻结修订、工具集合及依赖版本，进入共享运行时。
6. 工具调用继续走核心授权、参数校验、审计和结果归一化。

支持预览、创建、复制、修改、启停、删除、设为默认、导入与导出。导入仅处理声明与指令，不执行附带脚本，不带入授权票据或明文凭据；未知字段和路径按冻结 Schema 处理。

运行中切换先作为下次任务选择，不即时扩大当前轮工具集合。恢复任务优先使用记录的预设快照；依赖撤销或授权收紧时立即遵守新限制，不能以旧快照绕过撤权。

## 6. 系统接入

共享核心负责预设解析、作用域、修订、依赖解析与有效工具集合，桌面和 CLI 使用同一权威。UI 不自行拼接另一套系统提示或绕开核心工具过滤。

```text
本地预设定义 → 校验与依赖解析 → 启动快照
                                  ↓
                  共享 Agent 运行时与工具目录
                                  ↓
                     权限 / 审批 / 执行 / 会话日志
```

按照日志唯一业务真源原则，影响模型行为的最终指令、工具目录和选择信息必须由可重建的会话记录表达，并排除密钥。格式与事件名称实施前按现有日志协议冻结，不将本方案字段直接假定为现存 API。

候选接入域：共享 Agent、系统提示、工具注册、Skill、MCP、PTC、插件创建及现有模式控制器；需逐项核现有实现，避免重复开发。现有目录和类名存在不证明四种模式已闭环。

## 7. 页面与 CLI

设置中提供“Agent 预设”管理页：内置、自定义、作用范围、就绪状态、默认标记、模式说明及如何使用。新任务入口提供预设选择，显示实际工具与缺失依赖。

编辑器展示基本信息、指令、工具、Skill/MCP 引用、模型和预算；用户能看到来源及权限影响。AI 辅助创建保留候选预览与确认，不将生成成功当作安装成功。

CLI 提供相同的列出、查看、创建/导入、更新、删除、默认选择与启动时选择功能。命令名、Host 方法与有限 IPC 在实施前统一冻结，本文件不声明这些接口已经存在。

## 8. 安全与失败处理

- 预设指令不能修改审批策略、获取凭据或逃逸工具集合。
- 终端模式不等于无限权限；PTC 子调用与直接工具调用必须经过同样的守卫。
- MCP/Skill 引用不隐式安装、启动服务或触发认证，依赖缺失时显示待配置。
- 删除、禁用或更新定义不擅自杀死正在执行的任务；必要的停止操作另获用户授权。
- 预设导出不包含密钥、运行中的工单、会话内容或用户环境变量。
- 创建模式生成的插件与预设仍属于待审内容，不自动成为可信扩展。

## 9. 实施顺序与验收

依赖顺序：核上游预设契约及现有模式控制 → 冻结定义/权限语义 → 本地存储与修订 → 共享运行时工具过滤 → 四种真实执行路径 → 管理界面与 CLI → AI 辅助创建 → 打包态验收。依赖顺序不是范围裁剪，四种模式与自定义完整保留。

| 验收面 | 必须结果 |
| --- | --- |
| 定义与持久化 | 手写、复制和生成的定义均校验；重启后保留，非法定义不污染旧版本 |
| 并发编辑 | 旧 expectedRevision 被拒绝，桌面/CLI 不互相静默覆盖 |
| 标准模式 | 真实任务完成工具调用与结果结算，而非只显示模式名 |
| 极简模式 | 模型实际仅获允许的终端目录，其他工具直接和间接路径均不能越权 |
| PTC 模式 | 真实批量调用、汇总和错误处理；预算、取消和子调用授权生效 |
| 创造模式 | 可生成真实扩展或预设草稿，用户确认后才进入保存/安装流程 |
| 自定义 | 工具、Skill/MCP、模型与指令真实影响请求和执行，依赖缺失可解释 |
| 生命周期 | 修改不污染在途快照；撤权生效；删除定义不删除会话和依赖 |
| 本地范围 | 用户/项目同名不串用；未信任项目不自动启用预设 |
| AI 辅助创建 | 草稿不自动执行、设默认或扩大权限；确认取消不报已创建 |
| 双入口与恢复 | 桌面、CLI 对同一预设修订一致，任务恢复可重建实际选择 |
| 交付 | 新构建的桌面与 CLI 真实验证，不用单测或静态 UI 代替 |

关键反证：故意移除工具过滤、允许 PTC 越过审批、修改在途任务读取最新定义或让项目自动设默认，指定测试必须转红。测试报告带真实计数、退出码及凭据/环境前提，不用旧 PASS 推定当前完成。

## 10. 本轮结论

本地 Agent 预设方向可行，定位与用户提供的 基线“选择工具和工作方式”一致。方案不承诺 基线 配置格式或插件源码兼容，也不宣称已有四种模式的运行验收；本轮仅保存设计。
