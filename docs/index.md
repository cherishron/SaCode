# SaCode documentation

SaCode is a multi-platform AI assistant framework based on Provider abstraction. Use it to understand code, automate tasks, and build workflows with local project context across 10+ IM platforms.

## Install

Terminal window

```bash
pnpm install
```

Or install globally:

```bash
pnpm add -g @sacode/cli
```
