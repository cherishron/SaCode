四、API 实测（不照文档猜）
--------------------------
文档示例是 Compose 写法（`MarkdownView { attr { content(...) } }`），与本构件不符。
解包 KuiklyMarkdown-release.aar 后以 javap 读取真实签名：
- `com.tencent.kuiklybase.KuiklyMarkdownKt.KuiklyMarkdown(ViewContainer, String, MarkdownConfig,
   MarkdownComponents, MarkdownFlavourDescriptor, boolean)`
- `KuiklyStreamingMarkdownKt.KuiklyStreamingMarkdown(ViewContainer, MarkdownStreamingState,
   MarkdownBlock, MarkdownConfig, MarkdownComponents)`
- `MarkdownStreamingState.update(text, isEnd)` 返回块列表，可用于流式增量。
结论：它是 Kuikly DSL 的 `ViewContainer` 扩展，不是 Compose 组件；本轮取非流式入口
（`KuiklyMarkdown(content)`），流式入口留待气泡接入增量状态后启用。
