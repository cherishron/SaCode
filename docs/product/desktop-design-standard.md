# SaCode 桌面布局与品牌规范

日期：2026-10-03。技术栈沿用仓颉核心、Electron、Vue runtime、TinyVue 和 TinyRobot；渲染层仍用 `h()`，不引入模板编译器或第二份 Vue。

## 适用范围

适用于桌面所有新增及既有页面、组件、弹层和状态。本批统一已实现的会话、工具审批、预算与输入区。完整 DSH 面清单中的工作区/会话管理、设置、自动化、文档预览、可拆分窗格仍须接入真实数据并按本规范验收；导航锚点不算完成这些页面。

本仓当前没有 DSH 一手视觉稿、截图基线或完整令牌表，因此采用其工作台分区与行为约束，制定 SaCode 的统一视觉规范，不宣称像素级复刻。

## 品牌与语言

- 窗口标题、导航品牌、安装包产品名统一为 SaCode，固定界面文案使用中文；用户内容、模型输出和必要的文件名保持原文。
- 复用本仓旧分支 `codex/desktop-monkeycode-parity` 的 `interfaces/desktop/public/sa-logo.png`；不以其他产品标志或占位图替代。
- `scripts/pack-brand.ps1` 从既有标志按原比例生成带透明留白的 256px PNG 与 ICO，用于窗口及 Windows 可执行文件/安装包。品牌字样、形状和配色不重绘。
- 内部事件名、IPC 通道和日志格式保持兼容，不因界面中文化改写协议。

## 布局规则

| 对象 | 规则 |
| --- | --- |
| 栅格与间距 | 4px 基础栅格；间距令牌 4/8/12/16/24/32px，业务组件不另设一套间距 |
| 工作台 | 左侧导航、中央会话、右侧工具/预算；中央标题、内容及输入区共用左右基线 |
| 导航 | 常规宽度 184px；窗口不超过 1040px 时收为 64px 图标栏，仍保留中文无障碍名称 |
| 工具栏 | 常规宽度 280px，紧凑宽度 256px；分区标题、卡片与表单共用内容边界 |
| 控件 | 普通按钮、TinyVue 按钮、预算输入共用 36px 高度；折叠按钮为 28px；同行控件垂直居中 |
| 输入区 | 文字输入与发送按钮底边对齐；文本域可纵向调整，最小高度 80px |
| 消息 | 保留用户在右、其他角色在左；角色标签位于正文上方，正文可换行且长消息可展开/收起 |
| 图标 | 导航图标 18×18px，统一线宽和 `currentColor`；品牌标志 32×32px |
| 滚动 | 会话内容与工具侧栏分别滚动，标题和输入区不被挤出窗口；整页不得横向溢出 |
| 文字 | 统一 UI 字体；正文 13px，辅助信息 12px，主标题 18px；禁止无效的 font shorthand |
| 主题 | 亮暗主题共用语义色令牌，桥接 TinyVue/TinyRobot 色值；品牌底色保证标志可辨识 |
| 焦点 | 按钮、输入、导航均有可见 focus ring；纯图标导航仍具有可读名称 |
| 弹窗 | 复用 `SaCodeDialog` 原生模态组件；标题与关闭按钮同行且不随正文滚动，字段标签/值共用两列栅格；最大尺寸留出窗口边距，正文超高独立滚动，滚动条使用共享色令牌 |
| 模态键盘 | 打开后焦点进入弹窗，Tab 保持模态范围，Escape 关闭最上层原生 dialog，关闭后归还触发元素；关闭详情不隐式执行工具或审批 |
| 右侧标签页 | 工具与预算、文档预览、使用指南共用 36px 标签高度与同一内容边界；标签栏固定，内容独立滚动；方向键/Home/End 切换并同步焦点 |
| 待审批提醒 | 切换指南后保留工单；工具标签显示状态圆点及完整无障碍名称，指南提供返回处理入口，禁止因切页隐式批准或拒绝 |
| 文本预览 | 文件名、元信息与正文共用左右基线；正文使用等宽字体、保留换行并折行；显示会话中的读取快照而非宣称实时文件内容；无读取事实时显示空状态 |
| 拆分窗格 | 右侧主窗格与文本预览副窗格上下排列，共用左右基线，各自滚动；分隔条支持拖动、上下方向键、Home/End 和双击复位；比例限制 25%–75%，合并不改业务事实 |
| 浮动预览 | 共用 `SaCodeDialog` 非模态模式及读取投影；允许继续操作会话，标题/关闭按钮对齐，边距保持在窗口内；Escape 关闭当前焦点所在浮层，上层模态优先关闭 |
| 浮层移动与缩放 | 标题栏和右下角控件支持鼠标与方向键；最小尺寸 320×160px（受窗口可用尺寸限制），四边至少留 16px；窗口缩小时重新约束位置与尺寸，正文在浮层内滚动 |
| 错误区域 | 与正文/输入区共用水平内边距；长错误不裁剪正文，限高滚动，最大为会话区高度的 25% 且不超过 120px；运行按钮不因错误文本压缩 |
| 设置窗口 | 通用、模型、工具与扩展分类共用标签与内容边界；表单控件沿用 36px 高度，输入与应用按钮同行；预算复用核心读写通道，工具清单复用当前注册表，未接入的配置如实标明 |
| 桌面快捷键 | Ctrl+, 打开设置、Ctrl+L 聚焦输入、Ctrl+Shift+P 聚焦预览、输入区 Ctrl+Enter 发送；模态打开时拦截全局导航和发送，关闭后恢复原焦点；组合输入和重复按键不触发操作 |
| 表单处理中 | 同一业务操作在侧栏与设置共用忙碌状态；保留控件尺寸、暂时禁用输入/重复提交，状态文本由 aria-live 宣告、区域标记 aria-busy；响应结束后恢复操作 |
| 外观选择 | 当前会话提供跟随系统、亮色、深色；按钮共享高度与间距，aria-pressed 表达选择；核心完成落盘后才切换 Electron 主题并显示已保存，不以临时前端值宣称保存成功 |
| 会话列表 | 导航入口复用 18px 图标与 40px 行高；弹窗复用固定标题和独立正文滚动；卡片共用左右基线，标题与状态居中对齐，长标题省略并保留完整提示；目录、标题及保存数来自核心只读目录投影 |

## 验收方法

`npm run layout-smoke` 在真实 Electron 窗口生成八组截图及 `layout-report.json`：860×600（最小窗口）、880×640、1100×720、1440×900，分别覆盖亮暗主题。验收品牌加载、页面无溢出、列边界、预算输入/按钮同行对齐、输入区底边、控件高度、图标尺寸、审批卡边界、消息标签位于正文上方、中文导航与渲染隔离。工具、审批或消息未加载时须失败，不能用空集合判定通过。

`npm run ui-smoke` 继续验证消息分组、长消息折叠、真实审批往返、流式/取消、落盘投影与预算锁；中文化只更新展示断言，不削弱核心行为条件。

视觉检查须打开实际截图，检查所有断言覆盖不到的层级、留白和文字截断。打包后还须使用包内可执行文件复跑两类冒烟，核验 SaCode 名称及图标进入产物。只有当前页面通过不能推断未实现页面已完成。

工具详情同样覆盖八组主题/尺寸，每组另验弹窗边界、居中、字段行列对齐、关闭按钮高度与初始焦点。`ui-smoke` 用真实键盘事件验证 Tab 与 Escape，不用直接修改 DOM 代替交互。
