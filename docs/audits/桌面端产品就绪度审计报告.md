# SaCode 桌面端产品就绪度审计报告

> 审计范围：桌面端 = Tauri 桌面应用（`interfaces/desktop/`）+ 其依赖的 Rust 平台层（`kernel` / `runtime` / `interfaces/cli` / `integrations`）。
> 审计方法：分层静态检索 + 关键文件精读 + 发布/CI 配置核查。所有结论附带 `文件:行号` 证据，未修改任何源码。
> 审计日期：2026-10-01 ｜ 当前版本：`1.1.1`（根 `Cargo.toml`）

---

## 执行摘要

**核心结论：桌面端目前「无法上线」。**

底层 CLI/TUI 平台质量过硬（约 1266 个测试、fmt/clippy 门禁、三平台 CI、严格发布一致性脚本），但**真正面向用户的桌面 GUI 处于「MVP 壳 + 部分验收」阶段**，存在 4 项阻断性（P0）缺陷：

1. **IPC 能力白名单完全缺失** —— Tauri 2 强制 ACL，13 个自定义命令无一放行，桌面应用启动后所有原生能力调用都会被 `PermissionDenied` 拒绝，**等于不可用**。
2. **发布流水线根本不构建/发布桌面端** —— `release.yml` 只编 CLI 与 VSIX，无 `tauri build`、无桌面产物、无签名、无安装器发布。
3. **无 Windows/macOS 代码签名** —— Authenticode 与 Apple 公证均未配置，无法被系统信任安装。
4. **无安装器与自动更新** —— `bundle.active:false`，且未引入 updater 插件。

同时，平台层存在若干**高危安全/稳定性**隐患（密钥明文静默落盘、web.fetch SSRF、沙箱只读失效、生产代码逾千处 `.unwrap()`），这些必须在上线前收敛。

**亮点（值得肯定）：** 凭据卫生优秀（无硬编码密钥、走系统 keyring）；TUI 的 CJK 宽字符处理正确、取消真实有效；daemon token 永不离开 Rust 进程；发布一致性脚本（`check-release.js` / `check-vscode-release.js`）极为严格；依赖全部走 `Cargo.lock` 可复现。

## 二、按产品维度梳理「可上线标准」下的缺失要素

### 2.1 核心功能（Core）
- [ ] **桌面应用可运行**：IPC 能力白名单（P0 阻断）
- [ ] **可分发安装包**：Windows NSIS/MSI + macOS dmg/app + Linux deb/rpm（P0 阻断）
- [ ] **`serve --acp/--lsp` 真实组合启动**（当前为桩）
- [ ] 多窗口 / 多项目工作能力
- [ ] 跨平台文件夹选择

### 2.2 辅助功能（Auxiliary）
- [ ] 系统通知（任务完成 / 需审批 / 错误）
- [ ] 自动更新（签名增量更新通道）
- [ ] 窗口状态持久化（位置/尺寸/最大化）
- [ ] 离线模式与重连 UX
- [ ] CLI 自动补全
- [ ] 浅色主题 + 真彩探测
- [ ] 设置项完整暴露与导入/导出

### 2.3 稳定性（Stability）
- [ ] 前端全局错误边界 + 崩溃上报（P0 级体验阻断）
- [ ] Rust 端 `set_panic_hook` + TUI `SIGINT` 恢复（防终端卡死）
- [ ] 生产代码去 `.unwrap()`/panic，改为可恢复错误
- [ ] LLM 流式超时调优 + 429 重试
- [ ] stdin 流式/分块读取（防 OOM）
- [ ] 终端 PTY 工作线程 `catch_unwind`

### 2.4 安全性（Security）
- [ ] **密钥库失败不静默回退明文文件**（P0 高危泄露）
- [ ] **web.fetch SSRF 防护**（过滤内网/回环/云元数据 169.254.169.254）
- [ ] **沙箱只读模式真正阻止写入**（修复 `check_path` 空 `write_paths` 放行）
- [ ] 审批在 Plan 模式同样生效（当前仅 Build 模式）
- [ ] shell 命令黑名单升级为更稳健策略（或明确安全边界）
- [ ] daemon HTTP 审批接口鉴权/绑定范围确认（localhost + token）
- [ ] WebView CSP 启用（当前 `null`）
- [ ] 明文密钥文件 Windows ACL 收紧
- [ ] `cargo audit` / `cargo deny` 供应链扫描（CI）

### 2.5 可维护性（Maintainability）
- [ ] 有类型错误层级替代全栈 `anyhow`
- [ ] 安全/威胁模型文档（沙箱边界与 Yolo 风险说明）
- [ ] 收敛 `sandbox_guard` 双重实现
- [ ] `npm-package` 提交 `package-lock.json`（安装可复现）
- [ ] CI 测试 job 统一 `--locked` 口径
- [ ] `release.yml` 收窄 `NPM_TOKEN` 作用域至 publish step

### 2.6 测试覆盖（Test Coverage）
- [ ] **桌面端 E2E 测试**（Playwright/Webdriver，当前完全缺失）
- [ ] `interfaces/acp`（4 测试）、`interfaces/desktop/src-tauri`（8 测试）补强
