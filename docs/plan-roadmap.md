# SaCode 产品路线图

> 生成时间：2026-06-04 | 当前版本：0.1.23

---

## 产品定位

SaCode 是一个基于 Rust 的 AI 编程助手，支持 CLI/TUI 交互、多 Agent 编排、模型智能路由。当前功能集广度已达 beta 级别（0.5+），但几个关键存根使其尚未达到 1.0 就绪状态。

---

## 第一阶段：核心体验闭环（v0.3 之前优先）

| 功能 | 现状 | 实现要点 |
|------|------|----------|
| **SSE 实时流式输出** | `runtime/src/streaming/sse.rs` 空结构体 | 接入 ProviderClient 已有的 `StreamChunk`，实现 SSE 端点，TUI 实时渲染 token 级别输出 |
| **持久化任务存储** | `StoreDb` 空结构体，仅内存存储 | 实现 SQLite backend（`TaskStore` trait），任务队列/状态可跨进程重启恢复 |
| **Git Commit 工具** | `GitCommitTool` 空结构体 | 补充 `git.commit`/`git.branch`/`git.push`，实现修改到提交的闭环 |
| **apply_patch / diff_edit** | 缺失，仅 `fs.edit` 全量替换 | 实现行级精确编辑，支持 `search_replace` 风格的 patch 应用 |

---

## 第二阶段：代码智能深度（v0.5 左右）

| 功能 | 现状 | 实现要点 |
|------|------|----------|
| **代码 AST 解析** | `AstEditor` 空结构体 | 基于 tree-sitter 实现多语言 AST 解析，支持语义级重构（重命名、提取函数、移动模块） |
| **符号索引** | `SymbolIndex` 空结构体 | 构建项目级符号表，支持定义跳转、引用查找、调用链分析 |
| **LSP 诊断集成** | LSP 缺少 publishDiagnostics | 实现诊断推送，AI 可感知编译错误/警告，实现自动修复闭环 |
| **测试运行器工具** | 缺失 `test.run` | 自动发现和运行测试框架，AI 修改代码后可自动验证 |

---

## 第三阶段：生态与集成（v0.7 左右）

| 功能 | 现状 | 实现要点 |
|------|------|----------|
| **MCP stdio 传输** | 仅 HTTP remote | 支持 stdio 子进程方式接入本地 MCP 服务器，兼容社区生态 |
| **插件发现/分发** | `PluginLoader`/`PluginRegistry` 空结构体 | 实现 WASM 插件的自动发现（目录扫描）、注册、版本管理 |
| **检查点增量/自动恢复** | 基础全量 JSON 保存 | 增量快照、崩溃后自动恢复、检查点搜索与对比 |
| **IDE 插件** | ACP 协议已就绪但无客户端 | 开发 VSCode 插件，通过 ACP TCP 协议连接 SaCode 后台服务 |

---

## 第四阶段：智能化（v1.0+）

| 功能 | 现状 | 实现要点 |
|------|------|----------|
| **自动修复闭环** | 手动触发 | 编译-报错-分析-修复-验证 全自动循环，类似 `--watch` 模式 |
| **上下文感知路由** | TaskProfile 已有但策略简单 | 根据文件复杂度、语言特性、历史成功率动态选择模型 |
| **学习型记忆** | `AutoLearned` 类型定义但触发不明显 | 从用户交互中自动提取模式：常用命令、编码偏好、项目特定规则 |
| **多模态支持** | `media.read` 工具但不完整 | 截图→理解→修复的端到端流程，支持 UI 截图诊断 |
| **Agent 间协作协议** | 顺序/并行执行，无实时通信 | Agent 间消息传递、协商、投票机制 |

---

## 体验类优化（可穿插进行）

| 改进点 | 当前问题 | 建议方案 |
|--------|----------|----------|
| **增量上下文管理** | `client.rs` 每轮 `messages.clone()` 整个历史 | 滑动窗口 + 摘要压缩替代全量克隆 |
| **交互式审批流** | 沙箱有策略但审批体验弱 | 类似 Claude Code 的 "一键审批所有 diff" |
| **进度可视化** | TUI 有界面但缺并行进度 | 多 Agent 实时进度面板、任务依赖图 |
| **国际化** | 纯英文 | 中文输出支持，面向中国市场 |
| **用量统计** | 缺少 Token/耗时/成功率统计 | 量化 AI 效率提升，为计费和优化提供数据 |
| **导出/分享** | 缺少 | 会话导出 Markdown/JSON，配置分享，团队协作 |

## 架构依赖关系

```
kernel (URL常量、数据类型、FFI)
  ↑
runtime (流式、存储、工具、Agent、MCP、沙箱、检查点、记忆)
  ↑
interfaces/cli (TUI、REPL、命令行)
interfaces/lsp (语言服务器)
interfaces/acp (Agent通信协议)
```
