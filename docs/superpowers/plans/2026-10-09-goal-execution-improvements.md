# 持续目标改进实施方案与验收标准

> 实施代理按任务逐项执行，采用 `superpowers:subagent-driven-development` 或 `superpowers:executing-plans`；本文件为实施设计，不是实现完成或测试通过记录。

**目标：** 在默认不限总轮次的前提下，让持续目标具备启动前决策检查、有效进展保护、证据验收、可恢复预算和桌面/CLI/daemon 一致交互，避免假完成、无用消耗和无人知晓的等待。

**架构：** 仓颉共享核心负责目标生命周期、决策记录、进展判定、用量和验收裁决。Host、CLI、daemon 只做授权、传输、模型及通知适配；桌面仅展示核心投影和提交有限控制动作。所有模型可见内容和产品状态均可由会话日志重建。

**技术栈：** 仓颉 1.1.3、stdx、Node.js、Electron、Vue runtime、构建期 TypeScript 页面折叠；不增加运行时模板编译器或任意 IPC 方法通道。

**规格依据：** 本次对话已确认的产品方向、`docs/product/PRD.md` 的 F04 与 §4.1、现有目标源码；竞品参考为 https://qwenlm.github.io/qwen-code-docs/zh/users/features/goals/ 。Qwen 部分是官方文档声明，本次未运行 Qwen。当前本仓基线是工作区源码，不是隔离 HEAD 或安装包验收。

## 1. 已确认原则与实施配置

### 1.1 已确认的产品原则

1. 默认不设总轮次上限；持续有效推进不因轮次多而停止。无限轮次不等于无限 Token、无限重试或无限单次执行时间。
2. 必须防空转、重复失败、循环调用和大量无进展 Token 消耗。
3. 创建或编辑目标后立即检查关键决策与授权；能自行查明的先查，必须由用户决定的尽早集中提出，不能做少量工作后才暴露可预见阻塞。
4. 用户批准启动不等于批准所有文件写入、发布、删除、远程操作和权限变更。既有工具审批不能被目标授权替代。
5. 新问题需及时请求决策并通知；存在独立且已授权的工作时继续该部分，否则明确等待。不得擅自替用户拍板或反复发模型请求等回复。
6. 完成必须依据验收证据，不按工具调用次数判断；保留修订隔离、持久屏障与重启后显式恢复授权。
7. 完整范围包含目标起草、验收审核、预算恢复、交接报告与各入口对称控制；任务顺序只表达依赖，不缩成交付子集。

### 1.2 建议配置，不冒充已拍板数值

- 总轮次采用显式可空上限，缺省无上限；不用极大整数伪装无限。时间上限、目标 Token 总预算可配置且独立显示，不能因取消轮次上限而自动取消已有预算。
- 连续两轮无有效进展发一次纠偏提示，连续三轮仍无进展自动暂停，作为建议默认值，允许用户配置有界范围。
- 无进展 Token 阈值由用户设置或经模型能力与实测校准产生；实现和测试支持配置，不在此凭空指定统一 Token 数。
- 网络重试次数、请求超时、工具执行超时复用现有可用能力；缺失的适配面补齐并显式暴露，不用统一超时硬套长任务。
- 通知最低交付为桌面待决策卡片/徽标加系统通知、CLI 明确事件与 stderr 提示、daemon 持久投影加 SSE。外部邮件/手机推送不属本次范围；客户端断开时不能承诺通知已送达。

## 3. 核心契约

### 3.1 目标、修订与证据

目标实例采用独立 generation，目标正文或验收条件编辑采用 specRevision，普通暂停/恢复控制另用 stateRevision 做 CAS。不能再把所有控制变更与验收规格版本混为一谈。

目标规格包含结果、编号验收项、禁止事项、阻塞处理和用户允许的自主选择范围。预算属于运行时策略，不从正文中的自然语言自动解析成强制配置。

证据记录包含 generation、specRevision、criterionId、来源事件序号、类型和裁决；只允许引用实际存在、属于当前目标有效范围的日志事件。编辑后旧验收结果默认失效，可保留为历史上下文；新审核可重新核对原始事实，不能直接复制旧通过判定。

跨轮证据可用，不要求修改、验证和完成提案在同一轮。已变更文件的旧测试结果不能证明新版本通过；工具结果须有实际执行结果、退出状态或可核对产物版本。助手打印“测试通过”和目标文本都不构成执行证明。

### 3.2 状态与交互

运行阶段至少表达准备检查、等待决策、就绪、运行、审核、暂停、受阻、完成和清除；若继续使用既有 phase，必须以明确子状态投影，不能让 active 掩盖等待决策。

- 创建/编辑：保存新规格并触发只读准备检查，暂不进入受影响的执行动作。
- 准备检查：查询现有工作区，识别验收、方案、依赖和授权缺口。模型输出是分析提案，不是用户授权事实。
- 决策请求：携带稳定 requestId、会话、generation、specRevision、选项、推荐及影响。用户答案落日志，重复提交幂等，旧修订回答拒绝。
- 就绪：明示拟执行路径、检查命令、仍需逐次审批的操作及无人值守限制；用户显式启动后执行。界面不得将保存成功说成已经运行。
- 运行中编辑：旧轮结果可结算，但不得完成新规格；在下一安全点进行新规格准备检查，不强杀已启动的不可安全撤回副作用。
- 新阻塞：立即生成待决策事件。有可证明独立且已授权的工作则继续；仅靠模型自述“独立”不足以越过依赖。全部受阻时不继续模型轮次。
- 取消：中止当前可取消执行并暂停目标；暂停按已约定轮次边界生效，二者区别明确。
- 重启：重建目标和待决策事项，不重放工具副作用；执行授权默认撤销，用户明确恢复后才继续。

### 3.3 进展、循环和用量

每轮记录结构化进展依据：新验收结果、有效产物变化、新信息、排除候选原因或实际用户决策。工具成功、日志条数或修改时间单独不能证明进展；重复读同内容、重复计划、目标簿记不算进展。

只读调查可以产生进展，不要求每轮写文件；新信息需有可引用结果及与当前目标的关联，模型结论不能单独刷新计数。改动后立即还原等无净推进行为纳入循环检测。

操作指纹包含工具、规范化参数、目标资源状态及结果摘要。相同操作不自动判循环：分页游标前移、轮询目标状态变化和有界退避是合法推进；完全无状态变化的重复调用、A→B→A 振荡及相同错误累计才触发保护。检测既覆盖轮间，也覆盖同一轮工具循环。

无进展轮数与其 Token 消耗分别累计；有效推进才重置无进展段，纠偏提示或用户点击恢复不能自行清零逃过保护。恢复须携带新输入、改变后的条件或新的尝试策略；试跑窗口仍有界。

目标用量与会话用量两套归属读数不可混淆，来源仍是同一日志：目标主轮次、直接前台委派和验收调用计入目标；无关会话调用排除。后台任务保留单独账目和总体安全预算，不因不计入目标而无限消耗。缺供应商 usage 时显示未知/明确估算，不能记零并冒充预算保护生效。

用户可设置目标总 Token/时间/轮次上限；耗尽后显式扩额，累计用量不清零，只扩已选择窗口。保持会话级预算作为另一道独立闸。默认不限轮次不默认移除会话预算。

### 3.4 完成审核与交接

审核输入只含当前规格及可引用记录；确定性验收由核心检查适配结果，语义项交独立验证器。验证器无执行工具、不写工作区，记录是数据不是指令；不得自行批准操作或更改目标。

审核返回逐项通过/不通过/证据不足与事件引用。全部必需项通过、禁止事项未违反、所需用户决策有实际回答，才经修订 CAS 与持久屏障完成。超时、无可用结果、截断隐藏关键证据均不得通过；审核有次数/用量保护，不能拒绝后无限重审同一组证据。

证据请求有显式大小与截断元数据；不照搬 Qwen 固定字节数，按实际模型上下文容量构造。目标旧证据、隐藏推理和伪造用户确认不能被采纳。

停止报告包含完成/未完成项、最近有效证据、停止原因、目标与会话消耗、待决策事项和恢复动作。额度已耗尽时先从日志生成确定性报告；需要模型润色只可用显式有限交接预留，不越过硬预算悄悄追加请求。

## 4. 实施任务与依赖

任务顺序：T1 → T2/T3/T4 → T5 → T6 → T7 → T8。T2/T3/T4 概念上可并行，但相同文件编辑不可并行；完整交付须全部完成。

每任务执行顺序固定：写目标断言 → 运行确认失败 → 最小实现 → 专项回绿 → 注入错误语义验证指定用例变红 → 还原复跑 → 审查差异。提交仅在用户授权时执行，精确文件暂存，不自动提交。

**修改：** `core/src/goal.cj`、`goal_control.cj`、`goal_activation.cj`、`goal_test.cj`、`goal_control_test.cj`。

**新增：** `core/src/goal_spec.cj`、`goal_spec_test.cj`，用于结构化规格、代际及状态事件；不把业务挪到入口。

**输出接口契约：** GoalSpec（generation/specRevision/criteria/constraints）、GoalPolicy（可空限额）、GoalStatus（stateRevision/runState/activation/stopReason）。入口只能读取投影或提交带修订动作，不直接变更它们。

- [ ] 用例：新目标清量、编辑仅失效旧判定、控制不冒充规格变化；管道与多行目标完整回放；旧日志可读；陈旧动作不写事件。
- [ ] 准备/等待/就绪与运行不混淆，恢复后授权撤销；使用会话共享授权实例。
- [ ] 确定新事件 schema/version 和迁移读取规则，未知 required 事件不得静默解释。

- [ ] 两轮纠偏一次、三轮暂停按测试配置钉住；有进展打断连续段。
