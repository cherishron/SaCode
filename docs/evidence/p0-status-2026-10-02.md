## 明确不许做的 shortcut

不得用「删掉动态扩展」或「删掉 npm CLI」的方式让 P0 变绿；不得把 `TOTAL: 0` 的测试命令当绿灯
（`cjpm test` 对空测试集返回成功，见用户记忆「空测试集是假绿」）；结论只用 PASS / FAIL / BLOCKED。
