# 队列附件投影与滚动跟随回归（2026-10-05）

## 本轮改动

宿主 `queue/describe` 从核心持久化条目返回完整 `attachments` 引用数组，桌面将图片、文件引用与正文按顺序投影到 QueueDock。引用不包含上传字节或本地路径；编辑正文、重启宿主仍保留附件，删除条目移除引用。文件卡片显示名称与字节数，图片目前显示带名称的可访问图标；尚未接持久图片字节读取，不能据此宣称真实缩略图或原图预览完成。

会话折叠后的浏览器自动滚动事件可能晚于重新展开布局到达。原控制器把它误判为用户上翻，提前解除尾部跟随。现在待执行尾部定位期间保留跟随意图；滚轮等真实用户意图先取消定位，因此仍能进入阅读状态。
