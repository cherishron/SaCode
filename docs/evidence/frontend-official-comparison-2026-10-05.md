## 通用设置逐项验收清单

| 项目 | 当前缺口与必须证明的实际效果 |
| --- | --- |
| 新会话默认权限 | 持久默认值；只作用于新会话；实际工具审批采用相应有效策略；不能靠文案放宽授权 |
| 语言 | 当前只提供固定中文；官方选择项、可选语言及插件 locale 更新契约需逐项核对 |
| 外观 | 已接主题与系统跟随；保留保存失败、重启恢复和系统主题变化回归 |
| 字号 | 已接共享持久设置；限定会话内容，控制边界、重启和布局回归 |
| 工作步骤展示 | 缺少设置行及按档位展示真实工具调用的消费端；切换不得修改历史或执行行为 |
| 显示代码工作视图 | 缺少持久开关、轨迹与本轮差异的有效显示及完整 Agent 预设切换；没有数据时不能造差异 |
| 编辑快捷键 | 缺少编辑面板、冲突校验、持久保存和真实按键绑定；输入法及弹窗焦点需回归 |
| 网页链接打开方式 | 缺少偏好与点击消费端；分别验证应用内侧栏和系统浏览器；协议及打开范围由宿主约束 |
| 繁忙时发送行为 | 现有队列/即时补充后端不能代替设置；需验证 Enter、发送按钮与 Mod+Enter 的互补行为及草稿保护 |
| 性能与用量展示 | 缺少详细度设置与对应展示；首字时延、速率、上下文压力缺证据时显示不可用 |
| 当前版本与更新 | 需分别核对版本展示和桌面更新契约；不把源码版本或旧安装包当成当前运行版本 |
| 打开配置文件 | 后端确认文档可用性，固定动作打开对应文档；失败可重试，界面不接受任意路径 |
| 官方 Session Log 上传 | 按既定官方云服务绑定范围裁剪；本地日志查看与导出另行保留，不伪装为上传已接通 |

每项均须追溯功能插件、配置归属、共享核心/Host/CLI 适用性、前端消费端和自动化证据；状态目前保持部分完成。
