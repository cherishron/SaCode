# 持续目标控制协议与按目标计量（2026-10-05）

## 已接行为

共享仓颉核心增加 `goalProjectionJson` 和 `controlGoalJson`，固定六个方法：`goal/describe|create|edit|pause|resume|clear`。投影返回状态、正文、CAS 修订、完成轮数、累计轮次时长和连续无进展次数。没有对界面开放 `goal/complete`；完成仍须由执行证据通道判定。

GoalService 的所有写操作将 CAS 检查和事件追加放在同一会话锁内，防止同进程的协议线程与执行线程竞争。16 个并发写者使用同一修订时仅一笔成功，事件只追加一次。

GoalScheduler 从 none/complete 建立新目标时重置计量；同一目标编辑、暂停、恢复保留计量。新 `goal/round` 为 `<时长>|<进展>|<开轮修订>`，读取保留两字段旧格式支持。旧目标在被替代后才结束的轮次不能算到新目标。时长是已结束轮次的单调钟差值之和，包含轮内网络/工具等待，不含轮次间暂停；尚未把未结算轮次时长实时投影。

真实 Host 的读取与控制必须匹配当前活动会话身份；控制在既有租约内修改共享日志并 flush，单独控制则按既有写租约恢复/提交/释放。读面以持锁内存或新磁盘回放为源。运行中允许目标控制，暂停不调用 turn.cancel。

Electron preload/main 增加六个固定动作；主进程先检查会话、修订、正文、长度和额外字段，再转发给宿主。没有通用方法转发或完成动作。

## 起轮网络初始化修复

完整桌面测试揭示真实提供商的同步 `RealSseProvider` 构造会等 HTTP 响应头，阻塞协议线程并触发桥接的 5 秒 task/start 超时。新增共享核心 `DeferredProvider`：工厂只在模型执行线程首次 next 时调用；取消发生在读取之前则不连接，失败经 ModelAgentLoop 结算，资源仍由既有 finally 关闭。

宿主继续在起轮前同步检查配置及图片能力；仅把网络初始化推迟到执行线程。没有调大 RPC 等待时限，也不将网络失败伪装成功。初始化未完成时仍能读取状态、暂停目标与排队。
