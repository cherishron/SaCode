# 历史消息附件投影与展示（2026-10-05）

## 已接能力

共享仓颉核心 `projectMessageRows` 从一次日志事件快照生成消息行：事件身份、角色、正文及有序附件引用。附件仅归属于其对应用户消息，重复正文不用于关联；工具/助手正文沿用原 `modelSurfaceText` 语义，控制事件不伪装成消息。身份采用事件序号，在宿主重启及尾部窗口裁切后保持稳定。

宿主 `session/projection` 同时返回原兼容读面 `messages` 和新增 `messageRows`，二者来自同一组行、同一尾部 64 条窗口；全量计数仍保留。解析异常返回 `message-replay-rejected`，不会让协议进程因损坏引用抛出未捕获异常。新增字段没有 base64、宿主本地路径或任意文件读取接口。

桌面气泡及代码读取预览使用核心事件身份；文本内容仍沿用原角色/折叠/Markdown 派生。消息下的附件卡片显示文件名、字节数；图片卡片显示名称、固有宽高及明确的「图片引用」标记。文件名通过 Vue 文本节点渲染，不作 HTML 解释。
