# SaCode TUI 设计规范

## 当前主基线（2026-10-24 用户纠偏）

**文本引用续补**：固定上游`atCommandProcessor.ts`核实为工具读取正文而非仅路径；本仓普通文件附件尚不进模型，因此`@`发送采用Host read→工具结算→资料快照随消息持久化→task/start。确认披露正文保存与发送对象、默认取消，路径可翻页，缺失/截断/二进制整条拒绝，未知冻结；不在Node侧读取文件或伪装通用附件。补全仍只插路径。[本批证据](../../../docs/evidence/2026-10-24-cli-tui-text-references.md)。

**会话管理续补**：`/resume`按标题/ID/目录搜索，Ctrl+A切归档视图；`/rename`、`/archive`与恢复归档均默认取消。确认固定ID/修订，详情可翻页、操作区固定；48×18长标题不挤掉取消，面板持有唯一输入焦点。旧修订拒绝、未知冻结不重发；恢复归档不直接切换，当前会话先切走才可归档。底栏更新新标题但不重画Static旧历史。最终99/99、14合成帧与默认入口烟测通过，真终端/模型/安装待验。[证据](../../../docs/evidence/2026-10-24-cli-tui-session-management.md)。

**配置/模型细化**：`/auth`显示现有ID和默认指针，逐字段校验、Shift+Tab返回编辑、隐藏密钥跨返回保留但不重新显示。保存前重新核修订/ID、写后核回读；结果未知锁住重发并提示重新打开核对。`/model`只说明已配置/启用绑定，不用保存成功或选择成功冒充连通性。见[本批证据](../../../docs/evidence/2026-10-24-cli-tui-configuration-refinement.md)。

**能力浏览续补**：`/skills`只读目录/正文，`/mcp`注册/连接状态，`/permissions`/`/plan`只读模式；缺能力声明明确失败，不增加执行型假入口。此前Host过早缓存空工作区导致技能发现失败，已在源码修复、私有Host与真实TUI回归通过；默认旧二进制未覆盖，不把源码修复当整包刷新。见[根因与验证](../../../docs/evidence/2026-10-24-host-skill-workspace-cache-fix.md)；[原始失败记录](../../../docs/evidence/2026-10-24-cli-tui-capability-views.md)保留。

**默认开发入口刷新补记**：2026-10-24默认 `apps/desktop/dist/host` 已完整替换为修复版，709/709文件哈希一致，Host7/7、TUI73/73；无SACODE_HOST的显式tui/无参入口伪TTY均读到技能正文。以上旧二进制未覆盖表述保留为前轮时点，不再代表当前开发目录；桌面交付候选仍未重打，不把开发入口复验当安装态完成。

**工作区入口续补**：Home/End 固定Ink兼容、`@`工作区路径菜单与 `/diff` Host只读Git差异见[本批证据](../../../docs/evidence/2026-10-24-cli-tui-workspace-views.md)。`@`仅路径文字，不把补全当上传/读取成功；Git差异须绑定会话/目录/路径/范围，错误和未跟踪状态不伪装空修改，也不把用户原有修改归因给AI。

**最新实施**：[骨架重写](../../../docs/evidence/2026-10-24-cli-tui-skeleton.md)和[细节打磨](../../../docs/evidence/2026-10-24-cli-tui-polish.md)已按授权实施，下面的历史布局描述不再作为当前结构。当前标准模式是 Static 历史流，全屏翻阅可选；普通输入/选择/审批/配置互斥，工具卡在历史中内联。统一一行消息间距，避免相邻项双重留白；不增加未经请求的动画和自动操作。

当前内容支持轻量代码着色、引用/行内样式、表格宽屏成列/窄屏记录回退；词移动/撤销/历史搜索和工具详情展开均有键盘接线。审批预览标明“来自请求、非磁盘差异”，短屏优先保留工单、y/n和取消，默认拒绝。真实终端观感与实际模型任务仍待验，不把渲染帧当用户验收。

**交互与功能以 Gemini CLI 为参考；下方 Warp/Ollama 来源仅辅助配色与低装饰，不覆盖此基线。** 前两轮把 Gemini CLI 缩成聊天框再补键盘是执行偏差，不是用户缩减需求。固定上游 `google-gemini/gemini-cli@a3dd9f8c7bcb495a46d0b505b6f179996ccd8332`。此前“不拷贝源码”的自加限制撤销：可按 Apache-2.0 合规复制/适配独立展示组件，保留版权、许可证、修改说明与适用 NOTICE，不复制品牌、不引入 Gemini 业务引擎。当前布局仍未对齐；实际差异与待批准重构见[逐文件比较](../../../docs/evidence/2026-10-24-cli-tui-source-comparison.md)，下方布局描述是现状而非验收标准。

- 启动：SaCode 自有标识、版本、开始使用提示；工作目录和模型选择放底部。不能因装饰占满历史区或在紧凑屏强行大 banner。
- 命令可发现：输入 `/` 立即展示命令、说明、当前选择，↑↓/Tab/Enter/Esc 可操作，不只给帮助文字。
- 输入：多行、粘贴、移动/删除/草稿恢复，Ctrl+C 有输入先清空，运行中取消；不自动发粘贴或排队副作用。
- 主入口：本地模型选择、真实会话新建/恢复、真实目录切换、工具结果查看。成功必须以 Host 回执和回读为准。
- 菜单错误/未知写入：保留明确失败与恢复指引；不显示成功、不自动重试。
- 尚未对齐：认证/供应商表单、`@文件`、Markdown/代码高亮、内联差异、MCP/技能/计划/设置、全套按键等，见[对齐证据](../../../docs/evidence/2026-10-24-cli-tui-gemini-alignment.md)。不以本轮主骨架接通代替这些功能。

## 终端适配原则

1. **继承终端主题**：不改用户背景、字体或字号；正文使用默认前景色。网页的深色/白色背景、字体、像素圆角不照搬，浅色终端也须可读。
2. **颜色只表达语义**：cyan 用于当前输入提示与处理中；yellow 用于待审批/提示；red 用于错误；green 仅用于已完成工具。普通消息标签不再各用一种颜色。颜色不可替代状态文字。
3. **字格而非像素**：横向留 1 列外边距，正文缩进 2 列；块间空 1 行。标题通过粗体和位置区分，不堆大号 ASCII banner。
4. **少框线**：顶部与工具活动使用单边细线；输入框、审批与错误区才用单线边框。不增加渐变、闪烁或装饰动画。

实现 token 与断点集中在 [`src/theme.mjs`](src/theme.mjs)。

## 布局层级

从上到下：

1. **顶部**：`✦ SaCode CLI` 与版本；下一行是会话与本进程模型选择。目录在底部可见。
2. **对话区**：`› 你`、`· SaCode` 标签；正文缩进。空会话给一个具体示例，并说明需要模型配置，不把连接成功当作模型可用。
3. **工具活动**：独立紧凑区，最近最多 6 项；显示工具名、参数摘要、图标及文字状态；未知状态保留原值，不冒充成功。
4. **审批**：黄色单线框；工单号、工具、单次调用范围、明确标注为摘要的参数、`[y] 允许一次 / [n] 拒绝`。`d` 将对话区切换成完整参数视图，初始从参数开头查看，PageUp/PageDown 翻页；控制字节可见转义，不执行 ANSI。不新增审批模式或默认放行。
5. **输入区**：圆角线框与 `›` 提示符；多行编辑，显示光标附近 4 行（紧凑 2 行），长行在光标两侧截断，按字素编辑。输入 `/` 出命令菜单；审批期间优先答审批；运行中回车保留草稿，不暗中排队或发送。
6. **状态栏**：正常时是按键提示，运行时是取消提示，失败时是真实错误；右侧仅展示宿主返回的 token 计量，不虚构模型、连接状态或耗时。

## 紧凑窗口

- 宽度小于 64 列或高度小于 22 行时启用紧凑布局。
- 隐藏版本、空态示例、次要审批说明及 token 计量；工具活动最多 2 项。
- 保留会话/目录、工单号、工具、参数摘要、y/n、安全错误及取消提示。
- 顶部、工具、审批、输入与状态栏不被对话内容压缩；只有对话区允许收缩裁剪。对话按 Ink 实测字格高度翻页，默认贴底，PageUp/PageDown 查看宿主已返回的历史；不新增服务端分页。
- 自动化覆盖 100×30 与 48×18 的布局/resize；不据此宣称任意尺寸、字体、真实终端均已验。

## 不可越过的业务边界

只改变渲染，不更改 `session/append → task/start → turn/poll`、审批工单、取消与结算契约。不触碰用户密钥、模型配置、Host 或桌面入口。投影、工具状态和计量必须来自 Host；样例输出只能作为设计展示，不当真实任务证据。
