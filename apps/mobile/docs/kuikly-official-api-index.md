## 基础属性

所有 Kuikly 组件都支持以下基础属性：

### 样式属性
- `backgroundColor` - 背景颜色
- `backgroundLinearGradient` - 线性渐变背景
- `boxShadow` - 阴影效果
- `borderRadius` - 圆角
- `border` - 边框
- `visibility` - 可见性
- `opacity` - 透明度
- `touchEnable` - 触摸启用
- `transform` - 变换（缩放、旋转、位移）
- `zIndex` - 层级
- `overflow` - 溢出
- `clipPath` - 裁剪路径

### 布局属性
- `width` / `height` - 尺寸
- `maxWidth` / `maxHeight` - 最大尺寸
- `minWidth` / `minHeight` - 最小尺寸
- `margin` - 外边距
- `padding` - 内边距
- `flexDirection` - 排列方向
- `flexWrap` - 换行
- `justifyContent` - 主轴对齐
- `alignItems` - 交叉轴对齐
- `alignSelf` - 自身对齐
- `positionType` - 定位类型

### 基础事件
- `click` - 点击
- `doubleClick` - 双击
- `longPress` - 长按
- `pan` - 拖拽
- `animationCompletion` - 动画完成
- `layoutFrameDidChange` - 布局变化
- `willAppear` / `didAppear` - 显示事件
- `willDisappear` / `didDisappear` - 隐藏事件
- `appearPercentage` - 曝光百分比
