# SharedPreferencesModule

> 来源：https://kuikly.tds.qq.com/API/modules/sp.html

磁盘键值对缓存模块, 适用于数据量小的键值对缓存

## 写入方法

### setString方法
缓存字符串类型键值对

参数：
- `key`: String - 缓存key
- `value`: String - 缓存值

### setFloat方法
缓存Float类型键值对

参数：
- `key`: String - 缓存key
- `value`: Float? - 缓存值

### setInt方法
缓存Int类型键值对

参数：
- `key`: String - 缓存key
- `value`: Int? - 缓存值

### setObject方法
缓存**JSONObject**类型键值对

参数：
- `key`: String - 缓存key
- `value`: JSONObject? - 缓存值

## 读取方法

### getString方法
获取key对应的String类型的缓存值，当key不存在时返回空串

参数：
- `key`: String - 缓存key

### getInt方法
获取key对应的Int?类型的缓存值

### getFloat方法
获取key对应的Float?类型缓存值

### getObject方法
获取key对应的JSONObject?类型缓存值

## 鸿蒙侧说明

鸿蒙侧提供了两种 SharedPreferences 缓存实现：
- KRSharedPreferencesModule：基于 XML 文件读写，兼容所有 API 版本
- KROhSharedPreferencesModule：基于鸿蒙原生 oh_preferences C API（GSKV 格式），要求 OpenHarmony API 版本 ≥ 13
