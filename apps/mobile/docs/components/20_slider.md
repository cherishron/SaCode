# Slider(滑动器)

> 来源：https://kuikly.tds.qq.com/API/components/slider.html

滑动条组件

## 属性

### value
当前滑块值

### minValue
最小值

### maxValue
最大值

### step
步进值

### trackHeight
轨道高度

### thumbSize
滑块大小

### thumbColor
滑块颜色

### trackColor
轨道颜色

### selectedTrackColor
已选轨道颜色

## 事件

### onValueChanged
值变化回调
