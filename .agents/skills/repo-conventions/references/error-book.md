# H. 项目错题本（Error Book）

目的：把**踩过的坑**沉淀成项目内、可检索的**先验知识**。下次同类任务直接命中，跳过"探索 → 试错 → 修复"的多轮往返——**越用越准、越省 token**。

## 位置

`<docs 目录>/errors.md`（**入库**）。入库的原因：跨会话、跨 agent 共享，agent 起手即可检索。

## 一条错题记什么（模板）

```md
## E001 改目录名后漏改引用导致断链
- 日期：2026-10-24
- 领域：docs            # A 结构 / B docs / C 测试 / D 提交安全 / E 协作 ...
- 触发场景：重命名或移动文档 / 目录之后
- 现象：全库出现断链（引用仍指向旧路径）
- 根因：只改了文件，没同批重写引用
- 正确做法：改名后立即全局搜索旧名并重写引用，再跑断链校验
- 适用范围：任何改文件名 / 目录
- 状态：有效            # 有效 | 已失效（技术变化后标注，不删）
- 关键词：改名, 断链, 引用, 重写
- 证据：docs/evidence/…
```

## 写入时机（越用越聪明）

- **修完一个 bug / 踩完一个坑 / 发现一条"非显然约定"**时，收尾**同批追加**一条——与"文档同步规则"挂钩。
- 触发者是**任何 agent**，与协作领域（E）的收尾动作合并：更新进度 + 有坑就记错题 + 更新 CHANGELOG。

## 读取时机（省 token）

- **任务开始前**，用任务关键词在错题本里检索；命中相关条目→**直接遵循**，不再从零推断与试错。
- 与 E 看板分工：**E 看板**管"此刻谁做什么"，**错题本**管"过去学到什么"，互补不重复。

## 分类、去重、失效

- 按领域分组，可再按语言 / 模块。
- 同一根因**重复出现 → 合并并标注"复发 N 次"**，不堆重复条目。
- 失效条目**标注"已失效"保留不删**（防止旧知识换个马甲复活）。

## 边界

- 只记**可复现、有证据、可操作**的坑；不记情绪、无证据猜测。
- 只记**项目相关**的；通用语言知识不入本。
- **不自动注入模型**（避免污染上下文）——**按需检索**才读，这本身也是省 token 的一环。
