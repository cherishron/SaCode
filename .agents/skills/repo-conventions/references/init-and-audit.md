# F 新项目初始化 / G 项目体检

## F. 新项目初始化（清单式，一次立规矩）

1. **结构**：建约定目录（源码 / 文档 / 脚本 / 测试 / 配置），写**目录职责表**（见 [structure.md](structure.md)）。
2. **docs**：建 `docs/README.md` 总索引 + 各分类索引；写明**权威顺序**（需求权威 / 状态真源 / 历史快照）。
3. **测试**：约定测试位置与命名、一次性产物的临时根（见 [tests.md](tests.md)）。
4. **提交安全**：放 `.gitignore` 基线；约定 message 格式（见 [commit-security.md](commit-security.md)）。
5. **协作**：建 `docs/agents/` + 看板脚本 + 规则（见 [agent-collaboration.md](agent-collaboration.md)）。
6. **落地物**：以上约定写成**文本资产**（可复现），**不引入运行时依赖**。

输出：**初始化清单勾选表** + 已安装/写入的文件列表。

## G. 已有项目体检（只读优先）

1. **只读扫描**：目录树、docs 索引、测试布局、`.gitignore`、实际暂存差异、协作现状。
2. **分级发现**（P0 / P1 / P2）。
3. **最小修复建议**；高风险动作（搬目录 / 删除 / 重命名）**单独列**并须用户授权。

输出：体检报告 = 结论 + 分级发现表 + 修复清单 + 未覆盖与限制。

## 分级口径

| 级别 | 含义 | 例 |
|---|---|---|
| **P0** | 安全 / 阻断 | 真实凭据入库、产物入库、测试跑不起来却按通过宣称 |
| **P1** | 结构 / 一致性 | 无索引、多真源、测试与产物混放、无协作登记 |
| **P2** | 体验 / 债 | 命名不一致、message 含糊、文档可读性 |

## 边界

- 默认**只读**；落地须用户确认范围，不一次全改。
- **不重写历史**、不删冻结区、不擅自搬目录。
- 涉及提交 / 推送 / 发布，须独立授权。
