# Validate 阶段模板

## 阶段目标

全面验证实现质量，确保符合标准和需求。

## 验证流程

### 1. TypeScript 类型检查

```bash
# 运行类型检查
!npx tsc --noEmit

# 检查类型错误
"请检查是否有类型错误，并修复它们"
```

**类型检查清单**：
- [ ] 无类型错误
- [ ] 无隐式 any 类型
- [ ] 类型定义完整
- [ ] 泛型使用正确

**常见类型错误**：
```typescript
// 错误示例
function processData(data: any) {
  return data.value;
}

// 正确示例
interface Data {
  value: string;
}

function processData(data: Data) {
  return data.value;
}
```

## 常见问题

### Q: 如何处理验证失败？

A: 处理验证失败的步骤：
1. 识别失败原因
2. 分析错误信息
3. 制定修复方案
4. 执行修复
5. 重新验证

### Q: 验证需要多长时间？

A: 验证时间取决于：
- 功能复杂度
- 测试覆盖率
- 构建时间
- 人工测试时间

建议预留 20-30% 的项目时间用于验证。

### Q: 如何提高验证效率？

A: 提高验证效率的方法：
1. 自动化测试 - 编写自动化测试脚本
2. 并行验证 - 并行执行多个验证任务
3. 早期验证 - 在开发过程中早期验证
4. 持续验证 - 建立持续验证流程
5. 工具辅助 - 使用验证工具
