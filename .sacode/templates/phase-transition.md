# 阶段转换检查点

本文档定义了 PCIV 工作流各阶段之间的转换条件和检查点。

## 阶段转换流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Prime     │────►│   Clarify   │────►│  Implement  │────►│  Validate   │
│  (准备)     │     │  (澄清)     │     │  (实施)     │     │  (验证)     │
└─────────────┘     └─────────────┘     └─────────────┘     └──────┬──────┘
                                                                │
                                                    ┌───────────┴───────────┐
                                                    │                       │
                                                    ▼                       ▼
                                             ┌─────────────┐       ┌─────────────┐
                                             │   🎉 完成    │       │   🔄 循环    │
                                             └─────────────┘       └─────────────┘
```

---

## Prime → Clarify

### 转换条件

| 序号 | 条件 | 检查项 |
|------|------|--------|
| 1 | 项目上下文已加载 | 已读取 IFLOW.md 或 README.md |
| 2 | 技术栈已识别 | 已生成技术栈识别报告 |
| 3 | 需求已理解 | 需求描述清晰，功能点已列出 |
| 4 | 功能范围已定义 | 粒度已确定，边界已明确 |
| 5 | 初步计划已制定 | 主要阶段和任务已列出 |

### 检查清单

```markdown
## Prime → Clarify 检查清单

### 必须完成
- [ ] IFLOW.md / README.md 已加载
- [ ] 技术栈识别报告已生成
- [ ] 需求理解文档已完成
- [ ] 功能范围定义已完成
- [ ] 初步计划已制定

### 建议完成
- [ ] 技术栈参考模板已加载
- [ ] 风险初步评估已完成

### 转换确认
- 状态: [ ] 通过 / [ ] 不通过
- 确认人: _______
- 时间: _______
```

### 触发命令

```
/pciv-clarify
```

---

## Clarify → Implement

### 转换条件

| 序号 | 条件 | 检查项 |
|------|------|--------|
| 1 | 所有歧义已澄清 | 澄清问答记录完整 |
| 2 | 技术方案已确认 | 决策理由已记录 |
| 3 | 任务清单已分解 | 任务粒度适当，依赖明确 |
| 4 | 风险已评估 | 缓解措施已制定 |
| 5 | 用户已确认 | 获得明确确认 |

### 检查清单

```markdown
## Clarify → Implement 检查清单

### 必须完成
- [ ] 所有高优先级歧义已澄清
- [ ] 技术方案决策已记录
- [ ] 任务清单已分解（粒度 ≤ 4小时/任务）
- [ ] 任务依赖关系已明确
- [ ] 风险评估已完成
- [ ] 用户确认已获得

### 建议完成
- [ ] 所有歧义已澄清
- [ ] 可并行任务已标记
- [ ] 预计工时已估算

### 转换确认
- 状态: [ ] 通过 / [ ] 不通过
- 确认人: _______
- 时间: _______
```

### 触发命令

```
/pciv-implement
```

## Implement → Validate

### 转换条件

| 序号 | 条件 | 检查项 |
|------|------|--------|
| 1 | 所有任务已完成 | 任务状态全部为"已完成" |
| 2 | 自测已通过 | 即时验证无错误 |
| 3 | 代码已提交 | 变更已保存 |
| 4 | 文档已更新 | 相关文档已同步 |

### 检查清单

```markdown
## Implement → Validate 检查清单

### 必须完成
- [ ] 所有任务状态为"已完成"
- [ ] 自测验证通过
- [ ] 代码变更已保存
- [ ] API 文档已更新（如有）
- [ ] README 已更新（如有重大变更）

### 建议完成
- [ ] 单元测试已编写
- [ ] 注释已添加
- [ ] 代码已格式化

### 转换确认
- 状态: [ ] 通过 / [ ] 不通过
- 确认人: _______
- 时间: _______
```

### 触发命令

```
/pciv-validate
```

---

## Validate → 完成/循环

### 完成条件

| 序号 | 条件 | 检查项 |
|------|------|--------|
| 1 | 类型检查通过 | 无 TypeScript 错误 |
| 2 | 代码风格通过 | 无 ESLint 错误 |
| 3 | 功能测试通过 | 所有测试用例通过 |
| 4 | 构建成功 | 生产构建无错误 |
| 5 | 无阻塞性问题 | 无高优先级未解决问题 |

### 循环条件

| 问题类型 | 返回阶段 | 原因 |
|----------|----------|------|
| 类型错误 | Implement | 代码实现问题 |
| 代码风格问题 | Implement | 代码质量问题 |
| 功能测试失败 | Implement | 实现逻辑问题 |
| 需求偏差 | Clarify | 需求理解问题 |
| 设计问题 | Prime | 架构设计问题 |

### 检查清单

```markdown
## Validate → 完成/循环 检查清单

### 验证结果

| 验证项 | 状态 | 问题数 | 备注 |
|--------|------|--------|------|
| 类型检查 | ✅/❌ | [数量] | |
| 代码风格 | ✅/❌ | [数量] | |
| 功能测试 | ✅/❌ | [数量] | |
| 集成测试 | ✅/❌ | [数量] | |
| 构建验证 | ✅/❌ | [数量] | |
| 文档检查 | ✅/❌ | [数量] | |

### 决策
- [ ] 所有验证通过 → 完成交付
- [ ] 存在问题 → 循环迭代

### 循环决策
- 问题类型: _______
- 返回阶段: _______
- 原因说明: _______

### 错题记录
- [ ] 问题已记录到错题本
- [ ] 知识点已提炼
```

### 触发命令

```
# 完成交付
"功能已完成，准备交付"

# 循环迭代
"存在以下问题，返回 [阶段名称] 阶段处理"
```

## 状态持久化

### 状态文件位置

```
docs/pciv-status/
├── current-feature.md      # 当前功能点状态
├── tasks.md                # 任务追踪
├── decisions.md            # 决策记录
├── clarifications.md       # 澄清记录
├── validation-report.md    # 验证报告
├── mistake-book/           # 错题本
└── knowledge-base/         # 知识库
```

## 快速参考

### 转换命令速查

```
Prime → Clarify:     /pciv-clarify
Clarify → Implement: /pciv-implement
Implement → Validate: /pciv-validate
Validate → 完成:      "功能已完成"

# 循环命令
返回 Implement:       "返回 Implement 阶段处理"
返回 Clarify:         "返回 Clarify 阶段处理"
返回 Prime:           "返回 Prime 阶段处理"
```

### 状态查询

```
/pciv-status    # 查看当前状态
/pciv-continue  # 继续上一个任务
```
