# PIV 工作流完整模板

## 使用说明

这是一个完整的 PIV 工作流模板，您可以复制并根据实际需求修改。

## Prime 阶段

### 1. 加载项目上下文

```bash
# 加载项目核心文档
@IFLOW.md
@docs/core/architecture.md
@docs/technical/api.md
@docs/technical/development.md

# 理解项目结构
"请帮我理解这个项目的整体架构"
```

### 2. 明确需求和验收标准

```bash
# 描述需求
"我需要实现 [功能名称]，要求：
1. [需求1]
2. [需求2]
3. [需求3]
4. [需求4]
5. [需求5]"

# 明确验收标准
"验收标准：
- [标准1]
- [标准2]
- [标准3]"
```

### 3. 制定详细计划

```bash
# 请求 AI 帮助制定计划
"请帮我制定详细的实现计划，包括：
1. [步骤1]
2. [步骤2]
3. [步骤3]
4. [步骤4]
5. [步骤5]"
```

### 4. 评估风险和依赖

```bash
# 评估风险
"请评估实现 [功能名称] 可能遇到的风险：
- [风险1]
- [风险2]
- [风险3]
- [风险4]"

# 识别依赖
"需要哪些依赖？
- [依赖1]
- [依赖2]
- [依赖3]"
```

### 5. 确定技术方案

```bash
# 选择技术方案
"请帮我选择合适的技术方案：
- [方案1]：[描述]
- [方案2]：[描述]
- [方案3]：[描述]"
```

## Implement 阶段

### 1. 查看当前任务状态

```bash
# 查看当前计划
"请查看当前的实施计划，告诉我下一步应该做什么"

# 确认任务优先级
"当前任务的优先级是什么？是否需要调整？"
```

### 2. 选择下一个待办任务

```bash
# 选择任务
"开始实现 [任务名称]"

# 确认任务范围
"这个任务的具体范围是什么？需要修改哪些文件？"
```

### 3. 使用适当工具完成该任务

```bash
# 读取现有文件
@文件路径

# 修改文件
"请 [具体修改描述]"

# 验证修改
"请验证刚才的修改是否正确"
```

### 4. 验证结果并更新任务状态

```bash
# 运行验证命令
!验证命令1
!验证命令2

# 确认完成
"[任务名称] 已完成，请更新任务状态"
```

### 5. 重复直到当前阶段完成

```bash
# 继续下一个任务
"继续实现 [下一个任务名称]"

# 查看进度
"当前实施进度如何？还剩多少任务？"
```

### 6. 完成后更新相关文档

```bash
# 更新 API 文档
"请更新 [文档路径]，添加 [内容描述]"

# 更新架构文档
"请更新 [文档路径]，反映 [变更描述]"

# 更新开发指南
"请更新 [文档路径]，添加 [指南描述]"
```

## 注意事项

1. **渐进式实现** - 一次只做一个变更，完成后立即验证
2. **工具优先** - 使用代码编辑工具而非直接输出代码
3. **上下文保持** - 每步完成后更新任务状态
4. **文档同步** - 代码变更时同步更新文档
5. **质量优先** - 严格验证标准，确保代码质量
