# /pciv-status

查看当前工作流状态和进度。

## 描述

显示当前功能点的开发状态、任务进度、阶段信息等。

## 用法

```
/pciv-status
```

## 详细模式

```
/pciv-status --detail
```

输出更详细的信息：
- 所有文件变更记录
- 决策记录摘要
- 风险评估结果
- 错题记录统计

## 相关命令

- `/pciv-continue` - 继续任务
- `/pciv-prime` - 开始新功能
- `/pciv-implement` - 进入实施阶段
