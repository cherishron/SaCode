# /pciv-review

基于错题本和最佳实践的代码审查。

## 描述

执行代码审查，基于项目的错题本记录和最佳实践检查代码，发现潜在问题。

## 用法

```
/pciv-review [file]
```

### 参数

| 参数 | 描述 |
|------|------|
| `file` | 指定要审查的文件路径 |
| 无参数 | 审查最近变更的文件 |

## 审查维度

### 1. 错题本检查

检查代码是否重复之前记录的错误模式：
- 常见错误类型
- 已知反模式
- 历史问题模式

### 2. 最佳实践检查

对照最佳实践审查代码：
- 代码结构
- 命名规范
- 错误处理
- 性能考虑

### 3. 安全检查

检查常见安全问题：
- 输入验证
- 权限控制
- 敏感信息处理

### 4. 可维护性检查

检查代码可维护性：
- 代码复杂度
- 注释完整性
- 模块化程度

## 示例

```
用户: /pciv-review src/api/search.ts

AI: 正在审查代码...

### 加载错题本...
- 找到 3 条相关错题记录

### 执行审查...

#### ⚠️ 发现错题本匹配
根据 M-2026-02-15-003 记录，您之前遇到过类似的数据库查询问题。
建议参考该错题的解决方案。

问题: 未使用参数化查询
位置: src/api/search.ts:35
风险: SQL 注入
建议: 使用 Prisma 的参数化查询

#### 💡 代码改进建议
1. 第 42 行: 建议添加分页参数验证
2. 第 56 行: 建议添加缓存机制
```

## 与错题本联动

当审查发现与错题本匹配的问题时：
1. 自动引用相关错题记录
2. 提供之前的解决方案
3. 建议预防措施
