# /pciv-implement

启动 PCIV 工作流的 Implement（实施）阶段。

## 描述

Implement 阶段是 PCIV 工作流的第三阶段，主要任务包括：
- 按任务清单逐步实现
- 即时质量验证
- 更新任务状态
- 同步更新文档

## 用法

```
/pciv-implement [任务ID]
```

### 参数

| 参数 | 类型 | 描述 |
|------|------|------|
| 任务ID | 可选 | 指定要执行的任务ID，不指定则按顺序执行 |

## 前置条件

- Clarify 阶段已完成
- 任务清单已生成
- 用户已确认计划

## 执行流程

### 1. 加载任务状态

读取当前任务列表和进度。

### 2. 选择任务

- 自动选择下一个待办任务
- 或执行用户指定的任务

### 3. 执行任务

- 读取相关文件
- 编写/修改代码
- 创建测试文件

### 4. 即时验证

自动执行：
- TypeScript 类型检查（如适用）
- ESLint 检查（如配置）
- 基础语法验证

### 5. 更新状态

- 标记任务完成
- 记录变更内容
- 更新进度

### 6. 循环执行

重复步骤 2-5 直到所有任务完成。

## 自我验证

Implement 阶段支持双模式自我验证：

**即时验证（自动）**：
- 每次代码变更后自动运行
- 类型检查 + 代码风格检查

**手动触发**：
```
/pciv-check type    # 仅类型检查
/pciv-check lint    # 仅代码风格
/pciv-check         # 完整检查
```

- `/pciv-status` - 查看当前进度
