# /pciv-prime

启动 PCIV 工作流的 Prime（准备）阶段。

## 描述

Prime 阶段是 PCIV 工作流的第一阶段，主要任务包括：
- 加载项目上下文
- 自动识别技术栈
- 理解用户需求
- 定义功能范围
- 制定初步计划

## 用法

```
/pciv-prime [需求描述]
```

### 参数

| 参数 | 类型 | 描述 |
|------|------|------|
| 需求描述 | 可选 | 功能需求的自然语言描述 |

## 执行流程

### 1. 加载项目上下文

自动执行：
- 读取 IFLOW.md 或 README.md
- 读取项目架构文档（如存在）
- 读取开发指南（如存在）

### 2. 技术栈识别

自动执行：
- 检测 package.json、requirements.txt、go.mod 等配置文件
- 识别前端框架、后端框架、数据库、ORM、样式方案等
- 加载对应技术栈参考模板
- 生成技术栈识别报告

### 3. 理解需求

根据用户输入或提示用户描述需求。

### 4. 定义功能范围

- 确定功能点粒度（小/中/大）
- 明确范围边界
- 预估工作量

### 5. 制定初步计划

- 生成主要阶段划分
- 列出待 Clarify 确认的问题
- 初步风险评估

## 示例

```
用户: /pciv-prime 实现文章搜索功能，支持关键词、标签、分类组合搜索

AI: 正在执行 Prime 阶段...

## 技术栈识别
| 层级 | 技术 | 版本 |
|------|------|------|
| 前端框架 | React | 18.2.0 |
| 元框架 | Next.js | 14.0.0 |
| 数据库 | PostgreSQL | - |
| ORM | Prisma | 5.0.0 |

## 需求理解
- 功能名称: 文章搜索功能
- 主要功能点: 关键词搜索、标签过滤、分类过滤、组合搜索

## 功能范围
- 粒度: 中
- 预估工作量: 1-2 天

## 待 Clarify 确认的问题
1. 是否需要搜索结果高亮？
2. 搜索结果排序方式？
3. 是否需要保存搜索历史？

Prime 阶段完成。运行 `/pciv-clarify` 进入下一阶段。
```

## 相关命令

- `/pciv-clarify` - 进入 Clarify 阶段
- `/pciv-tech-check` - 单独执行技术栈检测
- `/pciv-context` - 重新加载项目上下文
